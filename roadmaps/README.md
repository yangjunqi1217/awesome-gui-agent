# Research Roadmaps

This folder is the profile-specific planning layer of the repository.

The root README and `docs/` should stay field-facing: paper lists, taxonomies, source maps, and mechanism-first research questions. Roadmaps here can be tailored to a researcher profile, but they should avoid names, affiliations, private project details, or other identifying personal information.

## Available Roadmaps

- [Video/VLM to GUI agents](video-vlm-to-gui-agent.md) - Reading and project path for a researcher profile with video understanding, VLM, temporal grounding, and multimodal representation experience.

## Privacy Rules

- Use abstract profile labels such as "video/VLM background" instead of personal identifiers.
- Keep private motivations, constraints, collaborators, timelines, and unpublished project details out of committed files.
- Put reusable research directions in `docs/`; put individualized reading order and fit analysis here.
