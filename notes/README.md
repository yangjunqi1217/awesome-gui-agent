When we actually read an item:

1. Copy the matching template from `notes/templates/`.
2. Save it under `notes/papers/`, `notes/repos/`, or `notes/products/`.
3. Replace the map status from `priority` or `watch` with a link to the note if the item becomes central.
4. Keep notes evaluative: core claim, evidence, failure modes, reproducibility, and whether we should use it.

Do not turn notes into abstracts. The value of this repo is our judgment.
