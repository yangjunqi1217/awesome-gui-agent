## One-line Takeaway

OpenCUA aims to provide open foundations for computer-use agents: data, models, benchmarks, and tools rather than only a single benchmark result.

## Problem

Computer-use agents are bottlenecked by closed models, private training data, inconsistent environments, and non-comparable evaluation setups. Open foundations are needed for reproducible research.

## Method

The repository describes an open CUA stack. We need to inspect the paper/report and release artifacts to separate data, model, environment, and evaluation components.
