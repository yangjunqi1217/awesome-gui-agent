## One-line Takeaway

UI-TARS is one of the most important industry-native GUI agent lines to track because it targets end-to-end GUI interaction as a native model capability.

## Problem

Most agent stacks bolt GUI control onto general VLMs or LLMs. Native GUI agents need training recipes, action formats, benchmarks, and productizable inference loops built for GUI interaction.

## Method

The report describes a GUI-focused model/agent approach with native action prediction. UI-TARS Desktop extends the work into an open multimodal agent stack.

## Evidence To Verify

- Model sizes and release availability.
- Action format and supported platforms.
- Training data sources and synthetic vs real trajectory mix.
- Reported benchmark scores and reproducibility.
- Relationship between UI-TARS, UI-TARS-2, and UI-TARS Desktop.

## Why It Matters To Us

This is a central industry baseline. It should be tracked alongside OpenCUA, ScaleCUA, UI-Venus, AutoGLM, and Mobile-Agent-v3.
